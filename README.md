# CalApp

Repositorio público de distribución de CalApp para Windows.

Versión estable actual: **1.0.2**.

[Descargar la versión más reciente](https://github.com/dt1cys/calapp/releases/latest)

## Novedades de la versión 1.0.2

- Nuevo campo **Unidades Aplicadas** en Diario e Historial; los registros anteriores siguen siendo compatibles y muestran «Sin Datos» cuando no contienen ese valor.
- Nombres de alimentos y titulares de cápsulas estandarizados con mayúsculas de título y conectores en minúscula.
- Normalización automática de nombres al crear, importar, recuperar o sincronizar alimentos.
- Alineación compacta de **Ver Nutrientes**, editar, mover y eliminar en la lista móvil.
- Actualización de la versión web con los cambios disponibles en escritorio.

## Conservación de datos

CalApp 1.0.2 conserva el mismo identificador de aplicación, perfil local y claves de almacenamiento de las versiones 1.0.0 y 1.0.1. Instalar la actualización sobre una versión anterior no elimina el diario, el catálogo, el perfil T1D, el tema ni los registros de bolo existentes.

La actualización automática descarga únicamente los artefactos adjuntos a las publicaciones estables. El instalador continúa sin firma digital, por lo que Windows puede mostrar una advertencia de SmartScreen.

CalApp es una herramienta personal de registro. No sustituye atención médica ni las alarmas oficiales del sensor.
